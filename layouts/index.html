01Internal agent platformIn progress · GA targeted Q1 2027Runtime / Release / Memory

Agent Platform

Teams own what an agent does.
The platform owns how it runs.

The mandate was one sentence: teams need to build and ship an agent in four hours. Every product team building an agent was re-solving the same undifferentiated problems: voice transport, observability, sessions, and release. The platform separates agent configuration from agent execution so those problems get solved once.

Product teams own prompts, tools, and configuration. The platform owns execution, versioning, eval-gated release, and deployment. I designed a code-first SDK path, and release control is chosen per agent: low-risk agents can ship with a click, while agents handling payments and personal data use CI-gated releases.

My role

Co-architect and co-owner of the platform. I own the voice plane, sessions, and long-term memory (Mem0), and designed the code-first SDK and Google Enterprise Agent Platform paths.

02Real-time agent systemsVoice / Streaming / Latency

A voice agent is
a systems problem.

I designed and built Agentix, the orchestration framework for RealPage’s production leasing AI voice agent, and led the product from prototype to GA. It currently handles about 6,000 calls a day, with 400,000+ units onboarded.

Profiling and optimizing the full audio pipeline cut median response time from about five seconds to about three seconds. In a separate 100-turn controlled study, local VAD reduced substantive-turn latency by 689 ms (22%; p < 0.001, Cohen’s d = 1.04).
